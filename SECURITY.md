# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

**Please do NOT open a public GitHub issue for security vulnerabilities.**

Instead, report security issues by emailing the Red Hat Product Security team:

- **Email:** [secalert@redhat.com](mailto:secalert@redhat.com)
- **PGP Key:** https://www.redhat.com/security/team/key/

For more information on Red Hat's vulnerability response process, visit:
https://access.redhat.com/security/team/contact/

## Supported Versions

Security updates are applied to the latest release. Older versions are not actively supported.
